# 🧠 Brainstormings — Sol de Nit

> Registro persistente de cada sesión de brainstorming para la carta de la pizzería. Cada sesión es un archivo independiente en esta carpeta.

## Convenciones

- **Un archivo por sesión**, nombrado con fecha + categoría: `YYYY-MM-DD-<categoria>.md`
- **Cada archivo contiene** obligatoriamente:
  - Contexto y restricciones activas
  - Ideas generadas (todas, sin filtrar)
  - Triage automático (✅ viable / ⚠️ caveat / ❌ ruptura)
  - Seleccionadas por David (Fase 3)
  - Descartadas (con motivo si lo hay)
  - Estado de fases del sistema
  - Pendientes para la sesión

## Sistema de fases

```
F1 DIVERGENCIA    →  Generar 15-20 ideas por categoría
F2 TRIAGE         →  Filtrar con el brief, etiquetar viabilidad
F3 SELECCIÓN      →  David marca favoritas
F4 REFINAMIENTO →  Variantes de las favoritas
F5 SHORTLIST      →  David elige 1-2 finalistas
F6 FICHA TÉCNICA  →  Ficha completa con sección de conservación
F7 MEMORIA        →  Reservadas / descartadas registradas aquí
```
